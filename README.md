# Projeto Final - Fundamentos de Banco de Dados

## Sistema Copa do Mundo 2026

Este projeto foi desenvolvido como atividade final da disciplina de Fundamentos de Banco de Dados. O objetivo é construir um sistema simples em Python integrado ao MySQL, utilizando o XAMPP, para praticar os principais conceitos vistos durante as 3 unidades da disciplina.

O sistema utiliza o cenário da Copa do Mundo 2026, com cadastro e manipulação de seleções, jogadores, estádios e partidas.

## Tecnologias utilizadas

- Python
- MySQL
- XAMPP
- mysql.connector
- Git e GitHub

## Estrutura do projeto

O projeto foi dividido em 9 etapas:

- `etapa1.py` - Criação do banco de dados e das tabelas
- `etapa2.py` - Inserção de registros nas tabelas
- `etapa3.py` - Consulta de dados
- `etapa4.py` - Atualização de registros
- `etapa5.py` - Remoção de registros
- `etapa6.py` - Criação dos relacionamentos entre tabelas
- `etapa7.py` - Consultas com JOIN
- `etapa8.py` - Funções de agregação
- `etapa9.py` - Sistema completo com menu interativo
